## Reading the diagrams

Each diagram has six bands:

1. **Header** with the student's name
2. **Cohort events strip** across Wks 1-10 (kickoff, syncs, reading groups, pulse, pilot, July 4, exit)
3. **Inbound handoffs** lane: what other students or infra feed into this student's work, and when
4. **Work streams** (3-4 per student): parallel tracks the student is building
5. **Outbound handoffs** lane: what this student hands off and to whom
6. **Final deliverables** panel on the right: what each stream ships and how it composes into the cohort's summer outputs

Two visual systems layer on top of the grid:

- **Green diagonal-hashed bands** behind task cells = **acceleration opportunities**. The "start: Wk N" marker on each band names the earliest week the work could begin without blocking on a teammate or a missing dependency. Wide hashing = lots of slack.
- **Violet chips + left-border accent** on task cells = **collaboration moments**. The chip names the cohort-mate(s) the student is actively working with that week.
